## Why choose no-rust?

In Rust, you can create many types of programs, and ensure your program remains safe. We C++ developers (commonly referred to as Real Programmers) think that this is a bad mindset: in order to be a Real Programmer, your code must be _exciting!_ Living on the edge is fun! Anyone who writes boring, safe code is a scaredy cat who doesn't understand Real Programming.

Every day, more C++ code is rewritten in Rust. Valuable bugs, some maintained for decades, are lost forever. At no-rust, we believe modernization shouldn’t mean abandoning your heritage. Our automated migration technology brings them to C++, where your engineers can finally take ownership of the problems Rust refused to let them have.
